# PawFinder

PawFinder is a community platform for reuniting lost pets with their owners through location-based reports, search, and private messaging.

The active application is in [`PawFinder-skeleton`](PawFinder-skeleton/README.md).

## Stack

- **Frontend:** React + Vite
- **Backend:** Java + Spring Boot
- **Build:** Maven
- **Database:** MySQL
- **Authentication:** Spring Security, JWT, and BCrypt

See the application README for setup, commands, and architecture details.
